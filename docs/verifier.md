# Verifier

The review agent does not decide that a task is done. Review judges the diff. The verifier judges the claim against evidence the harness already collected.

When an agent says done, the harness runs the gate before the turn closes. Build the projects the dirty set touches. Lint and format that set. Run the tests the metadata named. If a UI file changed, run the drive contract. Coverage comes back with the test run. None of this is the model.

A cheap model then reads the plan, the original request, and the agent's claims, and matches each requirement to a row: a clean problems panel, a test result, a coverage number, a drive trace. A claim with no row is open. The harness pushes that list back into the session and the agent continues. The agent does not get to close the turn.

The cheap model does not re-read the tree and does not re-run the tools. It only classifies. The loop has a cap. Past the cap the turn stays open and the panel shows the unmet rows, for the user.

Copilot or another online reviewer can still comment. Those comments are findings. They are not the gate.
